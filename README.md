The 3AM Fridge Text — one line a smart fridge texts its owner at 3am: "3am. Your midnight snack just texted me, worried about YOU. I'm the fridge. Go to bed." Role reversal is the joke: the snack is worried about the owner, and the fridge is the one breaking the news. 86 characters, one line, written to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
